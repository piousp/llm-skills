# AI-Tell Vocabulary: English Banned List

Read this file before writing in English. Keep it open while drafting.
The fix for a banned word is a rewrite of the sentence, never a synonym
swap. Detectors combine rhythm, predictability, and vocabulary markers;
changing one word leaves the other tells standing.

## Tier 1: hard AI-tell vocabulary

[NEVER] use these in any genre. When one is the exact right term, rewrite
the sentence around it.

| Word or phrase | Why it reads as AI |
|---|---|
| delve, dive, dive deep | filler metaphor for "read" or "explore" |
| tapestry, realm, landscape, journey, quest | grandiose stand-ins for plain nouns |
| navigating, in a world of, in a world where | canned opening scenery |
| nuance(s), multifaceted, transformative, pivotal | abstract praise with no content |
| robust, seamless, invaluable, profound, vibrant | empty intensifiers |
| moreover, additionally, furthermore, notably, crucially, hence | filler transitions |
| however (as a sentence opener) | routine pivot with no weight |
| "not only... but also" | formulaic contrast |
| "it's important to note", "it is worth noting" | throat-clearing |
| "in conclusion", "in summary", "in closing", "to sum up" | formula closers |
| "paving the way", "shed light on", "serves as", "testament to" | clichéd linking |
| "valuable insights", "the rise of", "it remains to be seen" | stock phrases |
| "glimpse into", "ever-evolving", "ever-changing" | filler outlook |
| "play a significant role in shaping" | overused to the point of parody |
| "notable works include", "aims to explore" | essay boilerplate |
| "today's fast-paced world" | canned context |
| showcasing, remarked, aligns, surpassing, tragically, impacting | marked overuse in generated text |
| embark, enlightening, esteemed, craft, crafting | inflated verbs and praise |
| imagine, game-changer, unlock, discover, skyrocket, boost | hype verbs |
| abyss, not alone, stark, testament | dramatic filler |
| revolutionize, disruptive, groundbreaking, cutting-edge | hype adjectives |
| utilize, harness, illuminate, unveil, intricate, elucidate | stiff formality |
| exciting, remarkable, powerful, inquiries | vague boosters and filler nouns |

## Tier 2: weak modifiers to trim

[DO] cut these when they add nothing. They are not hard bans: keep one
when the meaning needs it.

really, very, literally, actually, certainly, probably, basically, just,
maybe

Stacked hedges are worse than single ones. One hedge per claim, or none.

## Function words from the source list

The original appendix also lists can, may, could, that, it. These are
ordinary function words. [NEVER] treat them as banned words. [DO] cut
their filler uses, as in "the fact that" or "it is important to note
that".

## How to fix

- Filler transitions: cut them, or merge the sentence into the previous one.
- Formula closers: end on the last concrete point.
- Em dash: use a period, a comma, or a semicolon.
- Anything else: rewrite the sentence so the idea lands plainly. A synonym
  swap keeps the tell.
