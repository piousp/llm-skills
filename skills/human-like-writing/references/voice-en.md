# Voice-Locking and Few-Shot

Method for fixing a voice before writing, and for shaping text with the
author's own samples. Read by the English version of the skill.

### Voice-lock

Write a one-line voice description before drafting. It sets audience,
register, stance, and what to avoid. Keep it in view while writing.

Example: "Direct, specific, mildly opinionated, no hype. Short sentences,
plain words, concrete numbers."

The description is a constraint, not a decoration. Every sentence of the
draft is checked against it.

### Few-shot

Gather 3 to 5 real samples of the author's writing in the same genre as
the task. A sample shapes style better than any description.

How to use the samples:

1. Read them once and note recurring traits: sentence length, openings,
   punctuation habits, where opinions appear, level of formality.
2. Imitate those traits in the draft. Copy the rhythm, not the content.
3. If the author has no samples, write against the voice description alone.

Prompt pattern: "Here are 3 samples of the author's writing. Match their
rhythm, vocabulary range, and tone. Do not copy the content."
